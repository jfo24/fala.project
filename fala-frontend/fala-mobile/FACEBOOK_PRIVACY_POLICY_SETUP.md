# 🔒 Configuração da Política de Privacidade no Facebook Developers

## 📋 **O que o Facebook está pedindo:**

O Facebook Developers exige uma **URL de política de privacidade** para apps que coletam dados pessoais dos utilizadores.

## ✅ **Soluções Disponíveis:**

### **Opção 1: Hospedar a Política de Privacidade (Recomendado)**

#### **1.1. Usar GitHub Pages (Gratuito)**
1. **Crie uma conta** no [GitHub](https://github.com)
2. **Crie um repositório** chamado `fala-privacy-policy`
3. **Faça upload** do arquivo `PRIVACY_POLICY.md`
4. **Ative GitHub Pages** nas configurações do repositório
5. **URL será**: `https://seu-username.github.io/fala-privacy-policy/PRIVACY_POLICY.md`

#### **1.2. Usar Netlify (Gratuito)**
1. **Acesse** [Netlify](https://netlify.com)
2. **Faça upload** do arquivo `PRIVACY_POLICY.md`
3. **URL será**: `https://seu-site.netlify.app/PRIVACY_POLICY.md`

#### **1.3. Usar Vercel (Gratuito)**
1. **Acesse** [Vercel](https://vercel.com)
2. **Faça upload** do arquivo `PRIVACY_POLICY.md`
3. **URL será**: `https://seu-site.vercel.app/PRIVACY_POLICY.md`

### **Opção 2: Usar Gerador de Política de Privacidade**

#### **2.1. Geradores Gratuitos**
- [Privacy Policy Generator](https://www.privacypolicygenerator.info/)
- [Free Privacy Policy](https://www.freeprivacypolicy.com/)
- [TermsFeed](https://www.termsfeed.com/privacy-policy-generator/)

#### **2.2. Como usar:**
1. **Preencha** o formulário com informações do seu app
2. **Gere** a política de privacidade
3. **Copie** o HTML gerado
4. **Hospede** em qualquer serviço gratuito

### **Opção 3: Usar URL Temporária (Para Testes)**

#### **3.1. URL de Exemplo**
Para testes, pode usar temporariamente:
```
https://www.privacypolicygenerator.info/live.php?token=demo123
```

#### **3.2. URL do GitHub (Exemplo)**
```
https://github.com/facebook/react-native/blob/main/PRIVACY.md
```

## 🚀 **Configuração no Facebook Developers:**

### **1. Acessar Configurações**
1. **Vá para** o seu app no Facebook Developers
2. **Clique** em "Configurações" → "Básico"
3. **Encontre** a seção "Política de Privacidade"

### **2. Adicionar URL**
1. **Cole** a URL da sua política de privacidade
2. **Clique** em "Salvar alterações"

### **3. Verificar**
1. **Teste** se a URL abre corretamente
2. **Verifique** se o conteúdo está acessível

## 📝 **Conteúdo da Política de Privacidade:**

A política deve incluir:

- ✅ **Que dados coletamos**
- ✅ **Como usamos os dados**
- ✅ **Com quem partilhamos**
- ✅ **Como protegemos os dados**
- ✅ **Direitos do utilizador**
- ✅ **Contacto para questões**

## 🎯 **Recomendação:**

### **Para Desenvolvimento:**
Use a **Opção 3** (URL temporária) para testar rapidamente.

### **Para Produção:**
Use a **Opção 1** (GitHub Pages) para ter uma URL permanente e profissional.
