# Guia para Hospedar Política de Privacidade - Facebook Developers

## Arquivo Criado
✅ `privacy-policy.html` - Política de privacidade em formato web

## Opções para Hospedar

### 1. GitHub Pages (GRATUITO - RECOMENDADO)
1. Crie uma conta no GitHub (se não tiver)
2. Crie um novo repositório público
3. Faça upload do arquivo `privacy-policy.html`
4. Ative GitHub Pages nas configurações do repositório
5. URL será: `https://seu-usuario.github.io/nome-repositorio/privacy-policy.html`

### 2. Netlify (GRATUITO)
1. Acesse [netlify.com](https://netlify.com)
2. Faça drag & drop do arquivo `privacy-policy.html`
3. Obtenha URL automática: `https://nome-aleatorio.netlify.app`

### 3. Vercel (GRATUITO)
1. Acesse [vercel.com](https://vercel.com)
2. Faça upload do arquivo
3. Obtenha URL automática

### 4. Firebase Hosting (GRATUITO)
1. Acesse [firebase.google.com](https://firebase.google.com)
2. Crie um projeto
3. Ative Hosting
4. Faça upload do arquivo

## Configuração no Facebook Developers

1. Acesse [developers.facebook.com](https://developers.facebook.com)
2. Vá para o seu app
3. Em "Configurações" > "Básico"
4. Procure por "Privacy Policy URL"
5. Cole a URL da sua política de privacidade hospedada

## Exemplo de URL Final
```
https://seu-usuario.github.io/fala-privacy/privacy-policy.html
```

## Verificação
- ✅ URL deve ser acessível publicamente
- ✅ Deve mostrar a política de privacidade completa
- ✅ Deve estar em HTTPS (seguro)
- ✅ Deve estar em português (conforme o app)

## Próximos Passos
1. Escolha uma das opções de hospedagem
2. Faça upload do arquivo `privacy-policy.html`
3. Teste a URL no navegador
4. Adicione a URL no Facebook Developers
5. Salve as configurações

## Nota Importante
Lembre-se de atualizar os campos `[Seu endereço]`, `[Seu telefone]` e `[Seu nome]` no arquivo HTML antes de hospedar!
